# QTO references

Az itt tárolt QTO workbookok referenciaként használhatók az alábbiakhoz:

- adatstruktúra;
- taxonomy;
- UX;
- import/export;
- assembly modelling.

A bennük lévő alábbi tartalmak nem tekinthetők automatikusan validált magyar production rule-nak:

- fajlagosok;
- waste factors;
- productivity;
- material ratios;
- densities;
- engineering assumptions.

Nem használhatók automatikusan validált magyar mérnöki szabályként.

QTO referenciából származó production rule csak külön validálás után implementálható.
